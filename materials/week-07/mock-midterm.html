Slicing a list

Choose the value of each expression. Choose crashes if the expression stops the program.

1  closes = [190.5, 187.2, 193.8, 185.1, 191.4, 198.6]
Show the answer
  • closes[-2:] → [191.4, 198.6]
  • closes[1:4] → [187.2, 193.8, 185.1]
  • closes[6] → crashes
  • closes[::2] → [190.5, 193.8, 191.4]

Key idea: Start and stop are cuts between the boxes; the stop is not included; a too-big index crashes, a too-big slice does not.

M5 · 3 pt

Is this output plausible?

A colleague computes the average daily return of a price series, in percent. The program prints 2.5. Answer the three questions.

1  prices = [100.0, 110.0, 99.0, 108.9]
2  total = 0.0
3  for i in range(1, len(prices)):
4      change = prices[i] / prices[i - 1] - 1
5      total += change
6  average = total / len(prices)
7  print(round(average * 100, 1))
Show the answer
  • The daily returns are +10%, -10% and +10%. Is 2.5 a plausible average? → No
  • Why? → It divides by the number of prices (4), not the number of returns (3)
  • Which line causes it? → Line 6

Key idea: Do a rough check first: +10, -10, +10 average about 3.3, so 2.5 is too low. 3 returns, not 4 prices.

From a line of text to fields

One line read from a CSV file is split into fields. Choose the value of each expression.

1  line = "NESN,Nestlé,4,102.30\n"
2  parts = line.strip().split(",")
Show the answer
  • len(parts) → 4
  • parts[2] * 2 → '44'
  • float(parts[3]) → 102.3
  • parts[0] + parts[2] → 'NESN4'

Key idea: split gives STRINGS: "4" * 2 is "44". Convert with int()/float() before computing.

K4 · 1 pt

"w" and "a"

The program writes to log.txt several times. What number does it print?

 1  with open("log.txt", "w") as f:
 2      f.write("AAPL\n")
 3  for t in ["NESN", "VOO"]:
 4      with open("log.txt", "a") as f:
 5          f.write(t + "\n")
 6  with open("log.txt", "w") as f:
 7      f.write("MSFT\n")
 8  with open("log.txt", "a") as f:
 9      f.write("TSLA\n")
10  print(len(open("log.txt").read().splitlines()))
Show the answer
  • ✓ 2
  • Common wrong answers: 5 (thinks w also appends), 1, 3

Key idea: "w" empties the file the moment it opens it; "a" adds at the end. Count only what survives the last "w".
