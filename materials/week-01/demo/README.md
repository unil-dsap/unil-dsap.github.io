# Session 1 demo — the programs on the slides and in the workshop

| File | On the slides |
|---|---|
| `ledger.csv` | the three positions the whole session values |
| `ledger.py` | the ten-line program: value one position, then watch the price change |
| `wrong.py` / `right.py` | the same job with two lines swapped — one is your portfolio, both run |
| `portfolio.py` | workshop, part 4: three positions, a total, and a `round` whose answer is kept |

Open a file in the editor and press ▷. Every output on the slides is
from a real run of these files.

The scripts that derive the figures quoted on the slides (bits, floats,
transistor counts, the folder-size experiment, the Part 4 portfolio)
live in `../verify/` in the source repo and are not part of the course
material.
