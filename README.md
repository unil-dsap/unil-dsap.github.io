# Data Science and Advanced Programming — course site

Public website for DSAP (UNIL, HEC Lausanne), autumn 2026.
Served via GitHub Pages at https://unil-dsap.github.io/

- `materials/week-XX/` — session materials, revealed weekly after each
  Monday session (slides, worksheet, runnable demo).
- The site shell (schedule, syllabus pages) lives here too; content
  sources are maintained in a separate private repository and published
  here by the teaching team.

Students: nothing to install — the course runs on
[Nuvolos](https://nuvolos.cloud) cloud workspaces, free for enrolled
students.
